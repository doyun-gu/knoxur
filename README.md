# Knoxur

Personal multi-account portfolio tracker with multi-currency support (GBP, USD, KRW).

## Features

- Track holdings across multiple brokerage accounts
- Live stock prices via Yahoo Finance (all major exchanges)
- Multi-currency conversion with live FX rates
- Portfolio value over time with interactive charts
- Per-account breakdown and individual stock P&L
- Currency toggle — view everything in GBP, USD, or KRW

## Stack

- **Backend:** Python, FastAPI, SQLite
- **Frontend:** React, Vite, Recharts
- **Data:** yfinance (zero API keys required)

## Local Only

This is a private tool. All data stays on your local machines. No cloud, no external services, no accounts.
